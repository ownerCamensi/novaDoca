# NovaJS v2.0 — What's New

NovaJS just got a major upgrade. Version 2.0 brings mobile touch controls, a full tween animation system, mouse picking via raycasting, billboard sprites, a unified input manager, and a powerful texture loading pipeline.

Everything is still zero dependencies, pure WebGL2, and works directly in the browser with a single script tag.

---

## Quick Start

```html
<script src="novajs.bundle.js"></script>
<script>
  const engine = new Nova.Engine('canvas');
  const scene  = new Nova.Scene();
  const camera = new Nova.PerspectiveCamera(75, innerWidth / innerHeight);

  camera.position.z = 5;
  scene.add(new Nova.AmbientLight(0xffffff, 0.8));

  const cube = new Nova.Mesh(
    new Nova.BoxGeometry(2, 2, 2),
    new Nova.BasicMaterial({ color: { r: 0.6, g: 0.4, b: 0.9 } })
  );
  scene.add(cube);

  engine.start(scene, camera, (delta) => {
    cube.rotation.y += delta;
  });
</script>
```

## Touch Controls

NovaJS v2 ships with a complete mobile control system. All controls render on top of your canvas using DOM overlays and work on any touchscreen device. You can skin them with your own images using `addSprite()`.

### TouchAnalog — Virtual Joystick

The analog stick tracks touch position relative to its center and returns normalized axis values from -1 to 1.

```javascript
const stick = new Nova.TouchAnalog({
  position: 'bottom-left',  // 'bottom-left' | 'bottom-right' | 'bottom-center'
  size:     150,            // outer ring diameter in pixels
  nubSize:  60,             // thumb nub diameter in pixels
  opacity:  0.8,
  deadzone: 0.08,           // ignore tiny accidental inputs
  dynamic:  false           // true = spawns where finger first touches
});

// Skin it with your own images
stick.addSprite('base', './assets/joystick-base.png');
stick.addSprite('nub',  './assets/joystick-nub.png');

// Read axis every frame
engine.start(scene, camera, (delta) => {
  const { x, y } = stick.getAxis();  // x: left/right, y: up/down

  player.position.x += x * speed * delta;
  player.position.z += y * speed * delta;
});
```

**TouchAnalog options**

| Option | Type | Default | Description |
|--------|------|---------|-------------|
| `position` | string / `{x,y}` | `'bottom-left'` | Screen placement |
| `size` | number | `160` | Outer ring diameter (px) |
| `nubSize` | number | `64` | Thumb nub diameter (px) |
| `opacity` | number | `0.75` | Transparency 0–1 |
| `deadzone` | number | `0.08` | Ignore inputs smaller than this |
| `dynamic` | boolean | `false` | Spawn at tap location |
| `margin` | number | `24` | Edge margin (px) |

**TouchAnalog methods**

```javascript
stick.getAxis()        // → { x, y } normalized -1 to 1
stick.isActive()       // → boolean, true while finger is down
stick.addSprite(name, url)  // name: 'base' or 'nub'
stick.setOpacity(0.5)
stick.show()
stick.hide()
stick.destroy()

// Events
stick.onMove  = (x, y) => {}
stick.onStart = () => {}
stick.onEnd   = () => {}
```

### TouchDPad — Directional Pad

```javascript
const dpad = new Nova.TouchDPad({
  position: 'bottom-left',
  size:     140,
  opacity:  0.8
});

dpad.addSprite('dpad', './assets/dpad.png');

dpad.onDirectionChange = ({ up, down, left, right }) => {
  console.log('Direction changed');
};

// Poll in update loop
engine.start(scene, camera, (delta) => {
  const dir = dpad.getDirection();  // { up, down, left, right }
  const axis = dpad.getAxis();      // { x: -1|0|1, y: -1|0|1 }

  if (dir.right) player.position.x += speed * delta;
  if (dir.left)  player.position.x -= speed * delta;
  if (dir.up)    player.position.z -= speed * delta;
  if (dir.down)  player.position.z += speed * delta;
});
```

## Texture Loader

The new `TextureLoader` handles async loading with caching, generates procedural textures, and supports sprite sheet animation.

### Basic Loading

```javascript
const loader = new Nova.TextureLoader(engine.renderer.gl);

// Async / await
const wallTex = await loader.loadAsync('./textures/wall.png');
material.map  = wallTex;

// Callback style
const tex = loader.load('./textures/grass.png', (t) => {
  console.log(`Loaded ${t.width}x${t.height}`);
});

// Load many at once
const [tex1, tex2, tex3] = await loader.loadAll([
  './textures/albedo.png',
  './textures/normal.png',
  './textures/roughness.png'
]);
```

### Procedural Textures

Generate textures at runtime — no image files needed.

```javascript
// Checkerboard — great for testing UV maps
const checker = loader.generateCheckerboard(
  256,                      // size in pixels
  8,                        // number of squares
  [255, 255, 255, 255],     // color A (RGBA)
  [30,  30,  30,  255]      // color B
);

// Vertical gradient
const gradient = loader.generateGradient(
  256,
  [255, 100, 0, 255],   // top color
  [0,   100, 255, 255]  // bottom color
);

// Random noise (useful for animated shaders)
const noise = loader.generateNoise(256);

// From a canvas element (draw anything, use as texture)
const canvas2d = document.createElement('canvas');
const ctx = canvas2d.getContext('2d');
ctx.fillStyle = 'red';
ctx.fillRect(0, 0, 128, 128);
const canvasTex = loader.fromCanvas(canvas2d);

// Solid color (1×1 pixel, fast)
const red = loader.fromColor(255, 0, 0);
```

### Sprite Sheets

```javascript
// Load a sprite sheet (image with multiple frames in a grid)
const sheet = await loader.loadSpriteSheet('./spritesheet.png', 32, 32);
// frames are 32×32 pixels each

console.log(sheet.cols);        // number of columns
console.log(sheet.rows);        // number of rows
console.log(sheet.totalFrames); // total frame count

// Get a specific frame by grid position
const frame = sheet.getFrame(2, 0);  // column 2, row 0
// frame = { u, v, uw, vh }  — UV coordinates for that frame

// Animate — call every frame
engine.start(scene, camera, (delta) => {
  const frame = sheet.animate(delta, 12);    // 12 fps
  sprite.setFrame(frame);                     // apply to a Sprite object

  // Or get UV rect as Float32Array for a shader uniform
  material.uniforms['uvRect'] = sheet.getUVRect(frame);
});

// Play specific frames only
const walkFrames = [0, 1, 2, 3, 2, 1]; // frame indices
const frame = sheet.animate(delta, 8, walkFrames, true); // looping

sheet.reset(); // restart animation
```

## Sprite (Billboard)

A `Sprite` is a 2D textured quad that always faces the camera. Perfect for particles, floating icons, HP bars, trees at a distance, or 2D characters in a 3D world.

```javascript
const loader = new Nova.TextureLoader(engine.renderer.gl);
const tex    = await loader.loadAsync('./explosion.png');

const sprite = new Nova.Sprite(tex, {
  width:    2,      // world-space width
  height:   2,      // world-space height
  opacity:  0.9,
  rotation: 0,      // 2D spin in radians (independent of 3D rotation)
  cutoff:   0.01    // discard pixels with alpha below this (pixel-perfect edges)
});

sprite.position.set(5, 1, 0);
scene.add(sprite);

// Change tint color
sprite.setColor(1, 0.5, 0, 1);   // RGBA, 0–1

// Apply a sprite sheet frame
sprite.setFrame(sheet.getFrame(3, 0));

// Animate
engine.start(scene, camera, (delta) => {
  const frame = sheet.animate(delta, 10);
  sprite.setFrame(frame);
  sprite.rotation2d += delta; // spin
});
```

## Raycaster

Cast rays from the camera through a screen point to detect what the user is clicking or tapping on.

### Mouse Picking

```javascript
const ray = new Nova.Raycaster();

canvas.addEventListener('click', (e) => {
  // Automatically converts mouse position to NDC and builds the ray
  ray.setFromMouseEvent(e, canvas, camera);

  // Test against all meshes in the scene
  const hits = ray.intersectMeshes(scene.getRenderList());

  if (hits.length > 0) {
    const first = hits[0];  // closest hit
    console.log('Hit object:', first.object.name);
    console.log('Distance:',   first.distance.toFixed(2), 'm');
    console.log('Hit point:',  first.point);
  }
});
```

### Touch Picking

```javascript
canvas.addEventListener('touchstart', (e) => {
  const touch = e.changedTouches[0];
  ray.setFromMouseEvent(touch, canvas, camera);
  const hits = ray.intersectMeshes(enemies);
  if (hits.length) destroyEnemy(hits[0].object);
});
```

### Manual Ray

```javascript
// From normalized device coordinates (-1 to 1)
ray.setFromCamera({ x: 0, y: 0 }, camera);  // center of screen

// Intersect a sphere
const hit = ray.intersectSphere(center, radius);

// Intersect an AABB box
const hit = ray.intersectBox(minVec3, maxVec3);

// Intersect a plane (e.g. the floor)
const hit = ray.intersectPlane(
  new Nova.Vector3(0, 1, 0),  // normal (pointing up)
  0                            // distance from origin
);

// Get a point along the ray
const point = ray.at(5.0);  // 5 units along the ray
```

## Tween System

Smooth property animation with 20+ easing functions, chaining, looping, ping-pong, and delay.

### Basic Usage

```javascript
// Animate any object's numeric properties
new Nova.Tween(mesh.position)
  .to({ x: 10, y: 3 }, 1.5)         // target values, duration in seconds
  .easing(Nova.Easing.elasticOut)
  .start();

// REQUIRED: update every frame
engine.start(scene, camera, (delta) => {
  Nova.TweenManager.update(delta);
});
```

### Chaining

Play tweens in sequence:

```javascript
new Nova.Tween(mesh.position)
  .to({ y: 5 }, 0.4)
  .easing(Nova.Easing.quadOut)
  .chain(
    new Nova.Tween(mesh.position)
      .to({ y: 0 }, 0.8)
      .easing(Nova.Easing.bounceOut)
  )
  .start();
```

### Loop & Ping-Pong

```javascript
// Loop forever
new Nova.Tween(mesh.rotation)
  .to({ y: Math.PI * 2 }, 3)
  .loop(true)
  .start();

// Ping-pong (forward then backward, forever)
new Nova.Tween(light.position)
  .to({ x: 10 }, 2)
  .pingPong()
  .easing(Nova.Easing.sineInOut)
  .start();
```

### Callbacks

```javascript
new Nova.Tween(mesh.scale)
  .to({ x: 2, y: 2, z: 2 }, 0.3)
  .delay(0.5)                              // wait 0.5s before starting
  .onStart(() => console.log('started'))
  .onUpdate((target, t) => {              // t = 0 to 1 (eased)
    material.opacity = t;
  })
  .onComplete(() => {
    scene.remove(mesh);
  })
  .start();
```

### TweenManager

```javascript
Nova.TweenManager.update(delta);    // call every frame
Nova.TweenManager.killAll();        // stop all tweens
Nova.TweenManager.killOf(object);  // stop tweens on a specific target
```

## InputManager

Unified input across keyboard, mouse, touch, and gamepad — all in one place.

```javascript
const input = new Nova.InputManager(canvas);

engine.start(scene, camera, (delta) => {
  // ── Keyboard ──────────────────────────────────
  if (input.isDown('KeyW'))      moveForward();
  if (input.isDown('ShiftLeft')) sprint();
  if (input.isPressed('Space'))  jump();    // true only on the frame pressed
  if (input.isReleased('KeyE'))  interact();

  // Axis from WASD / Arrow keys
  const { x, y } = input.getKeyAxis();  // x: -1 to 1, y: -1 to 1
  player.position.x += x * speed * delta;
  player.position.z += y * speed * delta;

  // ── Mouse ──────────────────────────────────────
  console.log(input.mouse.x, input.mouse.y);     // screen position
  console.log(input.mouseDelta.dx, input.mouseDelta.dy); // movement this frame

  if (input.mouseDown(0)) console.log('left click held');
  if (input.mousePressed(2)) console.log('right click just fired');

  // Pointer lock (FPS mouse look)
  input.lockPointer();
  if (input.isPointerLocked()) {
    camera.rotation.y -= input.mouseDelta.dx * 0.002;
  }

  // ── Touch ──────────────────────────────────────
  const touches = input.getTouches(); // [{x, y}, ...]
  if (input.isTouching()) console.log(`${touches.length} fingers`);

  // ── Gamepad ────────────────────────────────────
  const pad = input.getGamepad(0);  // index 0–3
  if (pad) {
    const leftX  = input.gamepadAxis(0, 0);  // left stick X
    const leftY  = input.gamepadAxis(0, 1);  // left stick Y
    const aBtn   = input.gamepadButton(0, 0); // A button
  }

  // IMPORTANT: call at end of each frame
  input.update();
});
```

## Asset Loader

Batch-load textures, models, audio, and JSON before the game starts.

```javascript
const assets = new Nova.AssetLoader(engine.renderer.gl);

assets
  .add('hero',      'texture',     './textures/hero.png')
  .add('tiles',     'spritesheet', './textures/tiles.png', { frameW: 32, frameH: 32 })
  .add('gunModel',  'obj',         './models/gun.obj')
  .add('config',    'json',        './data/levels.json')
  .add('bgMusic',   'audio',       './audio/music.mp3')
  .onProgress((loaded, total, name) => {
    const pct = (loaded / total * 100).toFixed(0);
    loadingBar.style.width = pct + '%';
    loadingText.textContent = `Loading ${name}… ${pct}%`;
  })
  .onComplete((assets) => {
    const heroTex = assets.get('hero');
    const sheet   = assets.get('tiles');   // SpriteSheet object
    const config  = assets.get('config');  // parsed JSON
    startGame(heroTex, sheet, config);
  })
  .load();
```

## Clock

Accurate delta time with tab-switch protection.

```javascript
const clock = new Nova.Clock();

// In your own loop (if not using Engine)
function loop() {
  const delta = clock.getDelta();      // seconds since last call
  const total = clock.getElapsed();    // total seconds running
  // ... update scene ...
  requestAnimationFrame(loop);
}

clock.setMaxDelta(0.1);  // cap at 100ms — prevents physics explosions on tab resume
clock.stop();
clock.start();
```

## EventEmitter

Add event-driven behavior to any object.

```javascript
class Enemy extends Nova.EventEmitter {
  constructor() {
    super();
    this.hp = 100;
  }

  takeDamage(amount) {
    this.hp -= amount;
    this.emit('damaged', { amount, hp: this.hp });
    if (this.hp <= 0) this.emit('died', this);
  }
}

const enemy = new Enemy();

enemy.on('damaged', ({ amount, hp }) => {
  console.log(`Hit for ${amount}! HP: ${hp}`);
  spawnBloodParticles();
});

enemy.once('died', (e) => {
  scene.remove(e.mesh);
  score += 100;
});

enemy.takeDamage(40);
```

## Upgrading from v1

v2 is fully backward compatible. Everything from v1 still works exactly the same. Just add the new features on top.

```javascript
// v1 code — still works
const engine = new Nova.Engine('canvas');
const scene  = new Nova.Scene();
const camera = new Nova.PerspectiveCamera(75, innerWidth / innerHeight);
const cube   = new Nova.Mesh(new Nova.BoxGeometry(), new Nova.BasicMaterial());
scene.add(cube);
engine.start(scene, camera, (delta) => { cube.rotation.y += delta; });

// v2 additions on top
const stick = new Nova.TouchAnalog({ position: 'bottom-left' });
const ray   = new Nova.Raycaster();

new Nova.Tween(cube.scale)
  .to({ x: 2, y: 2, z: 2 }, 1)
  .easing(Nova.Easing.elasticOut)
  .pingPong()
  .start();
```

## Full Mobile Game Example

```javascript
const engine = new Nova.Engine('canvas');
const scene  = new Nova.Scene();
const camera = new Nova.PerspectiveCamera(75, innerWidth / innerHeight);

// Touch controls
const stick    = new Nova.TouchAnalog({ position: 'bottom-left', size: 140 });
const jumpBtn  = new Nova.TouchButton({ position: 'bottom-right', label: 'JUMP', size: 80 });
const attackBtn = new Nova.TouchButton({ position: 'bottom-right', label: 'ATK',  size: 70, offset: { x: 90, y: 0 } });

// Input manager
const input = new Nova.InputManager(canvas);

// Raycaster for tap-to-attack
const ray = new Nova.Raycaster();
attackBtn.onPress = () => {
  ray.setFromCamera({ x: 0, y: 0 }, camera);
  const hits = ray.intersectMeshes(enemies);
  hits.forEach(h => h.object.emit('hit'));
};

// Tween for damage feedback
function showHit(mesh) {
  Nova.TweenManager.killOf(mesh.scale);
  new Nova.Tween(mesh.scale)
    .to({ x: 1.5, y: 1.5, z: 1.5 }, 0.1)
    .easing(Nova.Easing.quadOut)
    .chain(new Nova.Tween(mesh.scale).to({ x: 1, y: 1, z: 1 }, 0.2))
    .start();
}

engine.start(scene, camera, (delta) => {
  Nova.TweenManager.update(delta);
  input.update();

  const { x, y } = stick.getAxis();
  player.position.x += x * 5 * delta;
  player.position.z += y * 5 * delta;

  if (jumpBtn.isPressed() || input.isPressed('Space')) jump();
});
```
