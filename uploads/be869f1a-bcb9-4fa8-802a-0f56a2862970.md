# Getting Started with NovaJS

Welcome to **NovaJS** — a modular, educational WebGL2 3D engine built from scratch for learning graphics programming, making games, and experimenting with shaders.

This guide will walk you through installation, your first 3D scene, and core concepts.

---

## Installation

### Option 1: Standalone (No Build Tools)

The simplest way. Just drop a script tag in your HTML and go.

```html
<!DOCTYPE html>
<html>
<head>
  <script src="novajs.bundled.js"></script>
  <style>
    body { margin: 0; overflow: hidden; }
    canvas { width: 100vw; height: 100vh; display: block; }
  </style>
</head>
<body>
  <canvas id="c"></canvas>
  <script>
    // Your code here
  </script>
</body>
</html>
```

**That's it.** Everything lives in `window.Nova.*`

### Option 2: Modular (Vite + ES6 Modules)

For larger projects:

```bash
unzip novajs.zip
cd novajs
npm install
npm run dev
# Opens http://localhost:5173 with hot reload
```

Then import modules:

```javascript
import { Engine, Scene, PerspectiveCamera, Mesh, BoxGeometry, BasicMaterial } from './src/novajs.js';
```

## Your First Scene — Rotating Cube

### Standalone Setup

```html
<!DOCTYPE html>
<html>
<head>
  <script src="novajs.bundled.js"></script>
  <style>
    body { margin: 0; overflow: hidden; background: #0a0a1a; }
    canvas { width: 100vw; height: 100vh; display: block; }
  </style>
</head>
<body>
  <canvas id="c"></canvas>
  <script>
    // Initialize engine
    const engine = new Nova.Engine('c');
    
    // Create scene
    const scene = new Nova.Scene();
    scene.setBackground(0.04, 0.04, 0.1, 1); // Dark blue
    
    // Create camera
    const camera = new Nova.PerspectiveCamera(
      60,                          // FOV in degrees
      window.innerWidth / window.innerHeight, // aspect ratio
      0.1,                         // near plane
      1000                         // far plane
    );
    camera.position.z = 5; // Move back so we can see the cube
    
    // Create a cube mesh
    const cube = new Nova.Mesh(
      new Nova.BoxGeometry(2, 2, 2),
      new Nova.BasicMaterial({
        color: { r: 0.8, g: 0.3, b: 0.9 } // purple
      })
    );
    scene.add(cube);
    
    // Add a light so we can see the cube
    scene.add(new Nova.AmbientLight(0xffffff, 0.8));
    
    // Start render loop
    engine.start(scene, camera, (delta, time) => {
      // delta = frame time in seconds
      // time = total elapsed time
      
      cube.rotation.y += delta * 0.8;  // Rotate around Y axis
      cube.rotation.x += delta * 0.3;  // Rotate around X axis
    });
  </script>
</body>
</html>
```

**What's happening:**

1. **Engine** — manages WebGL context, render loop, resize handling
2. **Scene** — container for all objects (meshes, lights, etc.)
3. **Camera** — defines what you see (perspective projection)
4. **Mesh** — a geometry + material combo placed in the scene
5. **Geometry** — the shape (BoxGeometry = cube vertices/indices)
6. **Material** — colors, shaders, textures
7. **Lights** — illuminate the scene
8. **Render loop** — called every frame; update object transforms here

## Core Concepts

### The Transform Pipeline

Every 3D object has three components that affect how it appears:

```javascript
const mesh = new Nova.Mesh(geo, mat);

// Position (world space X, Y, Z)
mesh.position.x = 5;
mesh.position.y = 2;
mesh.position.z = -3;

// Rotation (Euler angles in radians)
mesh.rotation.x = Math.PI / 4;  // 45° pitch
mesh.rotation.y = Math.PI / 2;  // 90° yaw
mesh.rotation.z = 0;            // no roll

// Scale (1.0 = normal size)
mesh.scale.x = 1.5;  // 50% bigger on X
mesh.scale.y = 1.0;
mesh.scale.z = 1.0;
```

Under the hood: **Model Matrix = Translation × Rotation × Scale**

The renderer applies this to every vertex:

```glsl
gl_Position = projectionMatrix * viewMatrix * modelMatrix * vec4(position, 1.0);
```

### Scene Graph

Objects can be **parented** to create hierarchies:

```javascript
const parent = new Nova.Mesh(geo1, mat1);
const child  = new Nova.Mesh(geo2, mat2);

parent.add(child);
scene.add(parent);

// Now when parent moves/rotates, child follows
parent.position.x = 5;  // child moves too
```

### Geometries

NovaJS includes common shapes:

```javascript
// Cube
new Nova.BoxGeometry(width, height, depth)

// Flat plane
new Nova.PlaneGeometry(width, height, segmentsW, segmentsH)

// Sphere
new Nova.SphereGeometry(radius, widthSegments, heightSegments)

// Donut
new Nova.TorusGeometry(radius, tubeRadius, radialSegments, tubularSegments)
```

Each has automatically generated:
- **Positions** — vertex coordinates
- **Normals** — for lighting calculations
- **UVs** — texture coordinates
- **Indices** — vertex order for triangles

### Materials

**BasicMaterial** — simple color + lighting

```javascript
const mat = new Nova.BasicMaterial({
  color: { r: 0.8, g: 0.3, b: 0.9 },
  opacity: 1.0,
  unlit: false  // false = use lights, true = full bright
});
```

**ShaderMaterial** — custom GLSL shaders

```javascript
const mat = new Nova.ShaderMaterial({
  vertexShader: glslCode,
  fragmentShader: glslCode,
  uniforms: {
    time: 0,
    customColor: [1, 0, 0]
  }
});
```

### Lighting

Three light types:

```javascript
// Ambient — lights everything equally
scene.add(new Nova.AmbientLight(0xffffff, intensity));

// Directional — like sunlight, has a direction
const dir = new Nova.DirectionalLight(0xffffff, intensity);
dir.position.set(5, 10, 5);
dir.target.set(0, 0, 0);  // Look at origin
scene.add(dir);

// Point — like a light bulb, radiates in all directions
const point = new Nova.PointLight(0xff0000, intensity, distance);
point.position.set(0, 5, 0);
scene.add(point);
```

All use **Lambertian diffuse** + distance attenuation.

## Common Tasks

### Animate a Mesh

```javascript
engine.start(scene, camera, (delta, time) => {
  // Spin
  mesh.rotation.y += delta * speed;
  
  // Bounce
  mesh.position.y = Math.sin(time * 2) * 2;
  
  // Orbit
  const radius = 5;
  mesh.position.x = Math.cos(time) * radius;
  mesh.position.z = Math.sin(time) * radius;
});
```

### Move the Camera

```javascript
engine.start(scene, camera, (delta, time) => {
  // Orbit camera around scene
  const angle = time * 0.5;
  camera.position.x = Math.sin(angle) * 10;
  camera.position.z = Math.cos(angle) * 10;
  camera.position.y = 3;
  camera.rotation.y = -angle;
});
```

### Use FPS Controls

```javascript
const controls = new Nova.FPSControls(camera, canvas, {
  moveSpeed: 8,
  sprintMult: 2,
  jumpForce: 5,
  groundY: 0
});

engine.start(scene, camera, (delta) => {
  controls.update(delta);
});

// WASD = move
// Mouse = look (click canvas to lock)
// Space = jump
// Shift = sprint
// C = crouch
```

### Load and Display a Custom Shader

```javascript
const vertexShader = `#version 300 es
precision highp float;
in vec3 position; in vec3 normal;
uniform mat4 modelMatrix, viewMatrix, projectionMatrix;
uniform mat3 normalMatrix;
out vec3 vNormal;
void main() {
  vNormal = normalize(normalMatrix * normal);
  gl_Position = projectionMatrix * viewMatrix * modelMatrix * vec4(position, 1.0);
}`;

const fragmentShader = `#version 300 es
precision highp float;
in vec3 vNormal;
uniform float time;
out vec4 fragColor;
void main() {
  vec3 col = sin(vNormal + time) * 0.5 + 0.5;
  fragColor = vec4(col, 1.0);
}`;

const mat = new Nova.ShaderMaterial({
  vertexShader,
  fragmentShader
});

const mesh = new Nova.Mesh(new Nova.SphereGeometry(1, 32, 24), mat);
scene.add(mesh);
```

### Add Physics (Gravity + Collision)

```javascript
const world = new Nova.PhysicsWorld();
world.gravity.y = -9.81;

// Add a static floor
world.addStaticBox(-10, -0.5, -10, 10, 0, 10);

// Add a falling box
const mesh = new Nova.Mesh(geo, mat);
mesh.position.set(0, 5, 0);
scene.add(mesh);

const body = world.addBody(new Nova.Rigidbody(mesh, {
  halfSize: new Nova.Vector3(0.5, 0.5, 0.5),
  friction: 0.8
}));

engine.start(scene, camera, (delta) => {
  world.step(delta);  // Update physics
});
```

### Create Multiple Objects in a Loop

```javascript
const meshes = [];

for (let i = 0; i < 10; i++) {
  const mesh = new Nova.Mesh(
    new Nova.BoxGeometry(1, 1, 1),
    new Nova.BasicMaterial({ 
      color: { 
        r: Math.random(), 
        g: Math.random(), 
        b: Math.random() 
      } 
    })
  );
  
  mesh.position.x = (i % 5) * 2.5 - 5;
  mesh.position.y = Math.floor(i / 5) * 2.5;
  mesh.position.z = Math.random() * 5;
  
  scene.add(mesh);
  meshes.push(mesh);
}

engine.start(scene, camera, (delta) => {
  meshes.forEach((mesh, i) => {
    mesh.rotation.y += delta * (0.5 + i * 0.1);
  });
});
```

### Particle Effects

```javascript
const particles = new Nova.ParticleSystem({
  maxParticles: 500,
  emitRate: 60,     // particles per second
  emitterType: 'fire'  // 'fire', 'smoke', 'sparks', 'snow'
});
particles.position.set(0, 2, 0);
scene.add(particles);

engine.start(scene, camera, (delta) => {
  particles.update(delta);  // Call every frame
});
```

### Post-Processing Effects

```javascript
const pp = new Nova.PostProcessor(
  engine.renderer.gl,
  window.innerWidth,
  window.innerHeight
);

pp.addEffect('crt');     // CRT monitor effect
pp.addEffect('bloom');   // Bloom glow
pp.addEffect('vignette'); // Dark edges

// Intercept render
const origRender = engine.renderer.render.bind(engine.renderer);
engine.renderer.render = (scene, camera, time) => {
  pp.begin();              // Render to texture
  origRender(scene, camera, time);
  pp.end(time);            // Apply post-fx
};
```

Available effects:
- `passthrough` — no effect
- `crt` — 80s monitor look
- `bloom` — bright glow
- `chromaticAberration` — RGB split
- `vignette` — darkened edges
- `pixelate` — blocky pixels
- `colorGrade` — cinematic color

## Important Notes

### Coordinate System

- **X** — left (-) to right (+)
- **Y** — down (-) to up (+)
- **Z** — back (-) to forward towards camera (+)

### Units

NovaJS has **no fixed units**. 1.0 could be 1 meter, 1 foot, 1 unit — you define it.

### Rotation Order

Rotations are applied **YXZ** (yaw, pitch, roll). This is natural for FPS cameras.

### Matrix Math

All matrices are **column-major** for WebGL compatibility. You rarely touch them directly, but know that:

```
projectionMatrix * viewMatrix * modelMatrix * vertexPosition = clipPosition
```

### Performance Tips

1. **Reuse geometries** — don't create new `BoxGeometry()` for each cube
2. **Batch similar objects** — group by material when possible
3. **Disable depth testing** for UI overlays with `gl.disable(gl.DEPTH_TEST)`
4. **Limit particle counts** — particles are GPU-fast but still have limits
5. **Use `unlit: true`** for simple materials to skip lighting math


## Troubleshooting

**"Mesh is invisible"**
- Camera is too close or too far away
- Light intensity is 0
- Material color is black
- Check `mesh.updateWorldMatrix()` is called

**"Shader compilation error"**
- Check GLSL version is `#version 300 es`
- Verify `uniform` declarations match your `setUniform()` calls
- Look at console for exact error line

**"Low frame rate"**
- Too many particles
- Too many draw calls — combine meshes
- Expensive post-processing effects
- Profile in Chrome DevTools > Performance

**"Browser says 'WebGL not supported'"**
- Use a modern browser (Chrome, Firefox, Safari 15+)
- Some mobile browsers disable WebGL — check settings
