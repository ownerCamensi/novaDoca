# Core Concepts

NovaJS is built on a modular architecture inspired by Three.js, Babylon.js, and game engines like Unity. Understanding these core concepts will help you build 3D scenes effectively.

## Scene Graph

The **scene graph** is a hierarchical tree structure that organizes all 3D objects in your scene.

```javascript
const scene = new Nova.Scene();
const camera = new Nova.PerspectiveCamera(75, window.innerWidth / window.innerHeight);

// Add objects to the scene
const mesh = new Nova.Mesh(geometry, material);
scene.add(mesh);

// Objects can have children (parenting)
const parent = new Nova.Mesh(geo1, mat1);
const child = new Nova.Mesh(geo2, mat2);
parent.add(child);
scene.add(parent);
```

When a parent's transform changes, all children transform relative to it. This is essential for building complex models — imagine a character with a body, arms, legs, and head all parented hierarchically.

## Transform Pipeline

Every 3D object has three transform properties:

- **position** — `Vector3` where the object is in 3D space
- **rotation** — `Vector3` Euler angles in radians (or use quaternions for gimbal lock prevention)
- **scale** — `Vector3` how big the object is

```javascript
const mesh = new Nova.Mesh(geometry, material);

// Position
mesh.position.set(5, 2, -3);
mesh.position.x = 10;

// Rotation (in radians)
mesh.rotation.y = Math.PI / 4; // 45 degrees around Y
mesh.rotation.x = Math.PI / 2; // 90 degrees around X

// Scale
mesh.scale.set(2, 2, 2); // 2x bigger
mesh.scale.y = 0.5;      // Half height
```

These get converted to a **model matrix** internally — a 4x4 matrix that combines all three transformations into one. The renderer then multiplies: `projection * view * model * position` to get the final screen coordinates.

## Geometry & Material

A **Mesh** is the combination of:
- **Geometry** — the shape (vertices, normals, UV coordinates)
- **Material** — how it looks (color, texture, shader)

```javascript
// Geometry defines shape
const geometry = new Nova.BoxGeometry(width, height, depth);
// const geometry = new Nova.SphereGeometry(radius, widthSegments, heightSegments);
// const geometry = new Nova.TorusGeometry(radius, tubeRadius, radialSegments, tubularSegments);

// Material defines appearance
const material = new Nova.BasicMaterial({
  color: { r: 0.8, g: 0.3, b: 0.5 },
  opacity: 1.0,
  unlit: false  // false = use lighting, true = full bright
});

// Mesh = Geometry + Material
const mesh = new Nova.Mesh(geometry, material);
scene.add(mesh);
```

### Material Types

**BasicMaterial** — solid color with lighting
```javascript
new Nova.BasicMaterial({
  color: { r: 1, g: 0.5, b: 0 },  // orange
  opacity: 0.8
})
```

**ShaderMaterial** — custom GLSL shaders for full control
```javascript
new Nova.ShaderMaterial({
  vertexShader: `#version 300 es
    // your vertex shader
  `,
  fragmentShader: `#version 300 es
    // your fragment shader
  `,
  uniforms: {
    time: 0,
    customParam: 42
  }
})
```

## Camera

The **camera** defines what you see. It has a position, rotation, and projection settings.

```javascript
const camera = new Nova.PerspectiveCamera(
  75,              // vertical field of view (degrees)
  width / height,  // aspect ratio
  0.1,             // near clip plane
  1000             // far clip plane
);

camera.position.set(0, 5, 15);
camera.rotation.x = -0.3;  // look slightly down

// In your update loop
engine.start(scene, camera, (delta) => {
  // Move camera around
  camera.position.x = Math.sin(time) * 10;
});
```

## Lighting

Lights make your scene visible and create depth. NovaJS supports three light types:

**AmbientLight** — uniform global illumination (no shadows)
```javascript
const ambient = new Nova.AmbientLight(0xffffff, 0.5);
scene.add(ambient);
```

**DirectionalLight** — like the sun, casts parallel rays
```javascript
const sun = new Nova.DirectionalLight(0xffffff, 1.0);
sun.position.set(10, 20, 10);
sun.target.set(0, 0, 0);  // look at origin
scene.add(sun);
```

**PointLight** — like a lightbulb, radiates in all directions (up to 4 per scene)
```javascript
const lamp = new Nova.PointLight(0xff4488, 2.5, 20);  // color, intensity, distance
lamp.position.set(5, 3, 0);
scene.add(lamp);
```

## The Render Loop

Every frame, you:
1. Update game logic (move objects, check collisions, etc.)
2. Render the scene with the camera
3. Repeat

```javascript
const engine = new Nova.Engine(canvas);

engine.start(scene, camera, (delta, totalTime) => {
  // delta = time since last frame (seconds)
  // totalTime = total elapsed time (seconds)

  // Update
  mesh.rotation.y += delta * 0.5;  // rotate 0.5 rad/sec
  
  // Physics, collisions, input, etc.
  world.step(delta);
  
  // Camera follows player
  camera.position.copy(player.position);
  camera.position.y += 1.7;  // eye height
});
```

The renderer automatically:
- Clears the screen
- Binds the scene's geometry
- Uploads uniforms (matrices, time, etc.)
- Draws all visible meshes
- Composites the final frame

## Vertices, Normals, UVs

Geometry data is stored as **flat typed arrays**:

- **Positions** — `Float32Array` of `[x, y, z, x, y, z, ...]` (3 floats per vertex)
- **Normals** — `Float32Array` of `[nx, ny, nz, ...]` (per-vertex normal for lighting)
- **UVs** — `Float32Array` of `[u, v, u, v, ...]` (2D texture coordinates, 0–1)
- **Indices** — `Uint16Array` of vertex indices (tells GPU which vertices form triangles)

```javascript
const positions = new Float32Array([
  // Triangle 1
  -1, -1,  0,   // vertex 0
   1, -1,  0,   // vertex 1
   0,  1,  0,   // vertex 2
]);

const indices = new Uint16Array([0, 1, 2]);  // one triangle

const geometry = new Nova.BufferGeometry();
geometry.setPositions(positions);
geometry.setIndices(indices);
```
