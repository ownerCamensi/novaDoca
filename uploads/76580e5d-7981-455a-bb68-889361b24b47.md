# API Reference

Complete reference for NovaJS classes and methods.

## Engine

**Constructor**
```javascript
new Nova.Engine(canvas)
```

**Methods**
- `start(scene, camera, updateFn)` — Start the render loop
  - `updateFn(delta, totalTime)` called each frame
- `stop()` — Stop rendering
- `destroy()` — Clean up resources

**Example**
```javascript
const engine = new Nova.Engine('myCanvas');
engine.start(scene, camera, (delta, time) => {
  // Update logic here
});
```

## Scene

**Constructor**
```javascript
new Nova.Scene()
```

**Methods**
- `add(object)` — Add object to scene
- `remove(object)` — Remove object
- `traverse(callback)` — Walk scene graph
- `setBackground(r, g, b, a)` — Set clear color
- `getRenderList()` — Get all renderable objects
- `getLights()` — Get all lights

**Properties**
- `background` — `{r, g, b, a}` clear color

## Object3D (base class)

Base for all scene objects. Extended by Mesh, Light, Camera, etc.

**Methods**
- `add(child)` — Add child object
- `remove(child)` — Remove child
- `traverse(fn)` — Recursively call fn on this and all children
- `updateMatrix()` — Recompute local matrix
- `updateWorldMatrix()` — Recompute world transform

**Properties**
- `position` — `Vector3` local position
- `rotation` — `Vector3` Euler angles in radians
- `scale` — `Vector3` scale factors
- `quaternion` — `Quaternion` rotation
- `matrix` — `Matrix4` local transform
- `worldMatrix` — `Matrix4` world transform
- `parent` — parent object or null
- `children` — array of child objects
- `visible` — boolean

## Mesh

**Constructor**
```javascript
new Nova.Mesh(geometry, material)
```

**Extends** Object3D

**Example**
```javascript
const mesh = new Nova.Mesh(
  new Nova.BoxGeometry(2, 2, 2),
  new Nova.BasicMaterial({ color: { r: 0.8, g: 0.3, b: 0.5 } })
);
scene.add(mesh);
```

## Cameras

### PerspectiveCamera

Standard frustum projection (like human eyes).

**Constructor**
```javascript
new Nova.PerspectiveCamera(fov, aspect, near, far)
```

**Parameters**
- `fov` — vertical field of view in degrees (75 typical)
- `aspect` — width / height
- `near` — near clip distance
- `far` — far clip distance

**Example**
```javascript
const camera = new Nova.PerspectiveCamera(
  75,
  window.innerWidth / window.innerHeight,
  0.1,
  1000
);
camera.position.set(0, 5, 10);
```

### OrthographicCamera

Parallel projection (no perspective). Good for UI, 2D games.

**Constructor**
```javascript
new Nova.OrthographicCamera(left, right, bottom, top, near, far)
```

## Materials

### BasicMaterial

Solid color with phong lighting.

**Constructor**
```javascript
new Nova.BasicMaterial(options)
```

**Options**
```javascript
{
  color: { r: 1, g: 0.5, b: 0 },  // RGB 0–1
  opacity: 1.0,                     // 0–1
  unlit: false,                     // skip lighting
  map: texture                      // texture object
}
```

### ShaderMaterial

Custom GLSL vertex + fragment shaders.

**Constructor**
```javascript
new Nova.ShaderMaterial(options)
```

**Options**
```javascript
{
  vertexShader: glslString,
  fragmentShader: glslString,
  uniforms: {
    time: 0,
    color: [1, 0, 0],
    customParam: 42
  }
}
```

**Required uniforms in your shader**
```glsl
uniform mat4 modelMatrix;
uniform mat4 viewMatrix;
uniform mat4 projectionMatrix;
uniform mat3 normalMatrix;

// In vertex shader
gl_Position = projectionMatrix * viewMatrix * modelMatrix * vec4(position, 1.0);
```

## Geometries

All geometries have `.setPositions()`, `.setNormals()`, `.setUVs()`, `.setIndices()` methods.

### BoxGeometry
```javascript
new Nova.BoxGeometry(width, height, depth)
```

### SphereGeometry
```javascript
new Nova.SphereGeometry(radius, widthSegments, heightSegments)
```

### PlaneGeometry
```javascript
new Nova.PlaneGeometry(width, height, widthSegments, heightSegments)
```

### TorusGeometry
```javascript
new Nova.TorusGeometry(radius, tubeRadius, radialSegments, tubularSegments)
```

### BufferGeometry

Raw geometry data for custom shapes.

```javascript
const geo = new Nova.BufferGeometry();
geo.setPositions(new Float32Array([x,y,z, x,y,z, ...]));
geo.setNormals(new Float32Array([nx,ny,nz, ...]));
geo.setUVs(new Float32Array([u,v, u,v, ...]));
geo.setIndices(new Uint16Array([0,1,2, ...]));
```

## Lights

### AmbientLight

Global ambient illumination.

```javascript
new Nova.AmbientLight(color, intensity)
```

### DirectionalLight

Sun-like parallel light.

```javascript
const light = new Nova.DirectionalLight(color, intensity);
light.position.set(10, 20, 10);
light.target.set(0, 0, 0);  // look at origin
```

### PointLight

Omnidirectional light (up to 4 per scene).

```javascript
new Nova.PointLight(color, intensity, distance)
```

## Math Classes

### Vector3

3D vector for positions, directions, scales.

**Methods**
- `set(x, y, z)` → this
- `clone()` → new Vector3
- `add(v)` → new Vector3
- `addSelf(v)` → this
- `sub(v)`, `scale(s)`, `dot(v)`, `cross(v)` → new Vector3
- `length()`, `normalize()` → scalar / new Vector3
- `applyMatrix4(m)` → new Vector3

### Matrix4

Column-major 4x4 transformation matrix.

**Methods**
- `identity()` → this
- `multiply(m)` → new Matrix4
- `transpose()` → new Matrix4
- `invert()` → new Matrix4
- `normalMatrix()` → Float32Array (3x3)

**Static methods**
- `Matrix4.perspective(fov, aspect, near, far)` → projection matrix
- `Matrix4.lookAt(eye, target, up)` → view matrix
- `Matrix4.compose(pos, quat, scale)` → transform matrix

### Quaternion

Rotation representation (avoids gimbal lock).

**Methods**
- `setFromEuler(x, y, z)` → this
- `setFromAxisAngle(axis, angle)` → this
- `multiply(q)` → new Quaternion
- `slerp(q, t)` → interpolated Quaternion
